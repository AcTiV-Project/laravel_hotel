# Hotel Web Reservation System

A web application developed with Laravel and MySQL to manage hotel reservations. The system allows customers to view and request a reservation via a form, while the information provided is stored in the database for later management by the administrator.

# Main features

- Customer reservation registration form.

- Registration of guest information and reservation details.

- Validation of data submitted through the form.

- Storage of reservations in MySQL.

- Management of routes and requests using Laravel.

- Dynamic views developed with Blade.

- Organized structure following Laravel's MVC architecture.

- Responsive web interface adapted to different devices.

- Integration between frontend, backend, and database.

# Technologies used

- Laravel

- MySQL

- PHP

- Blade

- HTML5

- CSS3

- JavaScript

- Vite


# Project objective

The objective was to develop a web solution that facilitates the reservation request process for customers and allows the centralization of reservation information in a database, creating a foundation for future hotel administration and management functionalities.

# What this project demonstrates

This project demonstrates knowledge in backend web development with Laravel, relational database management, form development, information validation, routing, MVC architecture, and communication between the different layers of a web application.
